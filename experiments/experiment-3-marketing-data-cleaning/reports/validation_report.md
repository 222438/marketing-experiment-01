# 数据校验报告（调用 validate-data）

## 结论：Share with noted caveats

可作为课堂数据获取与清洗实验交付。必须注明：历史评论、元数据历史 USD 价格、完整记录选择偏差、评论与商品的不同粒度。不能据此推断当前市场份额或销售额。

## 方法复核

- 从官方文件的 10,261 条评论中固定抽取 450 条，再连接 316 个商品；抽样前不按评分或品牌筛选。
- 清洗后 385 条、271 个商品、101 个品牌；不把样本评论数当成销售量。
- 64 条品牌缺失/Unknown、1 条空评论被排除。原始完整率和清洗完整率分开报告，不用排除后的分母伪装原始质量。
- 评论与商品连接为多对一，元数据重复键会报错，避免多对多连接导致重复计数。
- 日期从原始字符串规范化，并与 UTC Unix 秒核对。价格只规范小数显示，不换算币种、不替换价格。
- 0 有用票和 0 总票保留；未计算 0/0 比率。

## 独立核验

`scripts/validate_data.py` 已带 `--cache` 执行，核验两个压缩包 SHA-256，并把每条投影与完整源文件对应行直接比较。随后逐行比较 raw 值、clean 值以及原文；独立重算完整率，验证逐行日志一致；两次在临时目录清洗得到相同文件，原始数据哈希保持不变。实际输出在 verification.json。

- 450 原始行 = 385 保留 + 65 排除。
- 清洗后全部 13 字段完整率 100%，分母 385；原始品牌完整率 386/450＝85.78%。
- 10 条独立固定抽查与原始值相符。
- 385 行价格/评分/票数范围与时间交叉校验通过。
- 程序会验证重复键、缺字段、非数字、空 CSV、日期冲突和原始数据不变性。测试中的异常行是内存修改的验证输入，不属于提交数据。

## 页面与展示

通过实验一相同入口 `streamlit run app.py` 打开新增页面，复用 CSV 上传控件。价格明确为 USD。页面品牌筛选只改展示与导出，原始表仍为 450 行。实际浏览器上传、下载字节一致、缺字段报错结果见 browser_check.json；运行截图见 screenshots/experiment03.png。

本页不做价格/评分柱状图，避免将历史商品价格和评论加权均价混用；实验一图表保持原有功能。

## 仍需说明的局限

1. 评论来自公开历史样本，不能验证评论者实际购买行为；不代表今天的市场。
2. 排除品牌未知行可能影响品牌与评分分布；后续分析应比较排除前后，并始终报告样本量。
3. 单个商品可以贡献多条评论，商品价格分析应先按 ASIN 去重。
4. 正则隐私扫描能识别常见邮箱/电话，不保证识别所有隐私表达；已排除身份列并检查抽样文本。
5. 后续研究若需要销量、收藏数、实时价格，应另找真实来源，不得从本数据补造。
