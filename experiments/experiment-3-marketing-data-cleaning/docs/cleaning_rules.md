# 清洗规则及实际处理

## 删除、修改、保留

| 规则 | 实际结果 | 理由 |
|---|---:|---|
| 品牌空白或 Unknown | 排除 64 行（62 空白、2 Unknown） | 不具备品牌比较条件，不猜品牌 |
| 评论为空 | 排除 1 行 | 无评论证据，不生成评论填充 |
| 重复记录 ID/相同评论复合键 | 排除 0 行 | 没发现则记录 0，不注入假重复 |
| 价格非有限/非正/精度异常 | 排除 0 行 | 不设任意高价上限，不以四分位规则盲删真实高价 |
| 评分越界、非整数 | 排除 0 行 | 只接受 1–5 |
| 日期解析失败/与 Unix 时间冲突 | 排除 0 行 | 时间交叉核验，避免静默猜日期 |
| 有用票大于总票/负数 | 排除 0 行 | 保证互动量含义一致 |
| 日期格式规范化 | 修改 385 行 | 转成 ISO 日期，保留真实日期 |
| 评分 5.0 等规范化 | 修改 385 行 | 转整数字符串，不改变数值 |
| 价格小数位显示 | 修改 48 行 | 补足两位，不改价格值 |
| 商品名 HTML 实体 | 修改 18 行 | 例如 &amp; 解码；无语义改写 |
| 品牌 HTML 实体/别名 | 修改 29 行 | D&#39;Addario 等解码；Audio Technica → Audio-Technica |

品牌别名表只包括保守的空格/连字符变体 Audio Technica → Audio-Technica，原始品牌保留在 raw 文件及每条 changes 中。其他不熟悉的品牌保留原名，不能因未列在字典中而删除；也不强行合并 Joyo/Joyo Audio、OnStage/On-Stage Stands 等可能有歧义的名称。

逐行记录在 cleaning_log.csv：sample_row、record_id、源行号、keep/drop、删除原因、修改前后值。修改数可能重叠，不能将它们相加当作删行数。每行只记首个删除原因；后续条件不继续归责。

## 去重与不变性

有效行按 record_id 及 (asin, unix_review_time, review, rating, helpful_votes, total_votes) 检查重复，保留首次有效记录。缺陷行不会抢占后续合法记录的键。不同商品或不同日期的相同短评论不能自动视作重复。

原始 CSV 从不覆盖；输入输出为同一路径会报错。相同输入两次清洗得到相同 CSV、日志和质量统计；清洗后的数据再清洗也不变化。评论原文始终保持不变。

## 业务局限

清洗后完整率 100% 来源于规范化与排除无分析条件的行，不等于整个上游数据集都完整。留存 385/450＝85.56%，有完整记录选择偏差。源数据本身是历史乐器类评论子集，不可推广为全平台市场结论。
