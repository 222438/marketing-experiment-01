# 伦理检查表

| 项目 | 执行记录与结论 |
|---|---|
| 公开来源 | Stanford/UCSD 公开研究数据文件，下载地址在 source_manifest.json |
| 访问方式 | 仅 HTTPS 下载两个分类压缩包；不绕过登录、验证码或付费墙 |
| 请求量 | 复用本地缓存，重新运行先校验哈希；不反复请求 Amazon |
| 不虚构 | 对保留样本每个值执行源文件投影校验；没有生成器、伪造评论或缺失补值 |
| 数据最小化 | 不提交 reviewerID/reviewerName、用户链接、画像和完整源压缩包 |
| 评论中的联系方式 | 对 450 条原文执行邮箱/常见电话格式检测，0 个命中；抽查原文。格式检测不是识别所有隐私的保证 |
| 原始留存 | 原始隐私最小化样本以 SHA-256 固定；保留所有 450 行，包括后续排除记录 |
| 可解释处理 | 逐行日志记录 64 品牌缺失和 1 空评论的排除，其他规范化记录 before/after |
| 时间和价格 | 明确历史日期和 USD；不称为当前售价、真实成交价或实时采集 |
| 样本代表性 | 固定抽样只代表该公开子集；完整记录筛选也有偏差；不做全市场或因果判断 |
| 署名及使用 | 保留官方数据页和 SIGIR 2015 引用；第三方 Skill 按随附 Apache 2.0 授权保留原文件 |
| 敏感内容处理 | 不收集新的个人信息；评论文字如后续发现直接联系方式，应隔离该条并记录原因，而非悄悄改写证据 |

评分是评论者主观意见；采集到真实来源不等于验证所有评论描述的事实。样本用于课堂数据流程和方法验证。
